# Rusty Home visual identity

- Identity: house silhouette + Rust-colored R + cyan circuit traces.
- Primary vector wordmark: [logo.svg](logo.svg)
- Icon: [icon.svg](icon.svg)
- Social card candidate: [social-preview.svg](social-preview.svg)
- Product tagline: **Home automation, reimagined in Rust.**
- Surface `#081a2c`; copper `#e67836`; cyan `#18bcd8`;
  near-white `#f6fbff`; muted blue `#9db6c9`.

Use **Rusty Home** for the product. The old HA-Rust-Bridge technical crate
names will be migrated without breaking compatibility. Avoid final-release,
ready-to-install or complete Home Assistant compatibility claims. Any
screenshots must explicitly distinguish synthetic demonstration from real
household data. Do not use the Home Assistant logo as Rusty Home's emblem.

The files here are original source vector artwork, not third-party assets.

The project-authored visual assets are covered by the root MIT license;
third-party project names and logos remain their respective owners' marks.

Desktop and mobile PNG dashboards are rendered from the actual web frontend\nusing isolated synthetic data on GitHub Actions. The SVG lab dashboard remains\nan explicitly illustrative vector mockup.\n
